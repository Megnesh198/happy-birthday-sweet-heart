# Meghna — 10-page Birthday Experience ❤️

## Pages
1. index.html — welcome
2. unlock.html — password gate
3. letter.html — love letter
4. love-story.html — relationship timeline
5. memories.html — photo gallery
6. reasons.html — reasons interaction
7. universe.html — starry universe
8. birthday.html — interactive cake
9. promises.html — forever promises
10. finale.html — final surprise

## Run
Extract the ZIP and open index.html. VS Code + Live Server is recommended.

## Set password
Edit js/config.js and replace YOUR_SECRET_PASSWORD with your chosen password, e.g.
const SECRET_PASSWORD = "our-special-day";
This is a fun surprise gate, not high-security authentication.

## Add photos
Place images in images/ with these exact names:
meghna-main.jpg, photo-1.jpg, photo-2.jpg, photo-3.jpg, photo-4.jpg, photo-5.jpg, photo-6.jpg

## Add music
Place your own MP3 at music/our-song.mp3. Visitor must tap the music icon to start playback.

## Personalise
Edit letter.html, love-story.html, promises.html and the reasons array in js/main.js.
Birthday date used: 19 November 2026.
